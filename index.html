How to check whether a workflow fits your study
  1. Match the assay and input. Confirm data type, file format, organism, genome/reference or database release, and the tutorial’s starting point.
  2. Check the study design. Verify sample IDs, biological replicates, pairing, batches, controls, and the exact comparison before selecting statistical steps.
  3. Make the run reproducible. Record pipeline and tool versions, reference/database releases, parameters, sample sheet, and run reports. nf-core records version information and recommends versioned runs and test profiles.
  4. Test execution separately from scientific validity. A small test profile checks that software and infrastructure run; it does not establish that the method or biological conclusion is correct for your study.
  5. Review evidence and QC. Check expected quality metrics, negative/positive controls, benchmarks or known-answer data when available, and whether the result is robust to reasonable analysis choices.

Published Galaxy histories and workflows can expose tool versions and parameters for review. Tutorials are starting points: adapt them only after checking their inputs, assumptions, and current documentation.
